# 学习计划

## 第一阶段  单片机与工具基础

- 完成开发环境安装和下载调试
- 掌握 GPIO、外部中断、定时器和 PWM
- 掌握串口日志输出
- 学会使用万用表和示波器进行基础测量

## 第二阶段  电机与传感器

- 驱动直流电机或无刷电机
- 读取编码器并计算转速
- 接入循迹、距离或姿态传感器
- 完成基础 PID 速度闭环

## 第三阶段  智能小车

- 完成供电、主控、驱动和传感器接线
- 实现循迹、避障或遥控功能
- 进行整车联调和故障保护
- 整理原理图、代码说明和测试结果

## 第四阶段  电赛能力

- 学习运算放大器与信号调理
- 学习 ADC、DAC 和常用传感器接口
- 学习稳压电源和基础电源设计
- 进行限时方案设计和模块联调训练
