# 智能小车与电赛学习仓库

这个仓库用于记录智能小车、电控和电子设计竞赛相关的学习过程。建议将能够复现的源码、硬件资料、调试记录和阶段成果持续提交到这里。

## 当前目标

- 熟悉 STM32 或 GD32 的基础开发流程
- 掌握 GPIO、定时器、中断、PWM、ADC 和编码器采集
- 学习 UART、I2C、SPI 和 CAN 等常用通信接口
- 完成电机驱动、传感器读取和 PID 速度闭环
- 完成一辆具备循迹、避障或遥控功能的基础智能小车
- 学习原理图、PCB、焊接检查和软硬件联调
- 积累电赛常见模块及系统综合设计经验

## 目录说明

```text
smart-car-learning/
├── firmware/       单片机程序和工程说明
├── hardware/       硬件接线、器件资料和原理说明
├── pcb/            原理图、PCB 和生产文件说明
├── docs/           学习计划、调试记录和项目文档
├── tests/          台架测试和验证记录
├── .gitignore      不需要提交的编译产物
└── README.md       项目总说明
```

## 建议的第一个项目

建立 `firmware/motor-speed-control/`，完成以下内容：

1. PWM 控制电机转速
2. 编码器读取实际转速
3. 串口输出目标值和测量值
4. 加入 PID 速度闭环
5. 记录阶跃响应、超调量和稳态误差

每完成一个小阶段就提交一次，不要等整个项目结束后一次性提交。

## 提交信息示例

```text
初始化智能小车学习仓库
完成编码器读取
增加电机速度 PID 控制
修复低速时编码器计数异常
补充电源模块调试记录
```

## 使用约定

- 源码、原理图、PCB、说明文档和测试结果应提交
- Keil 编译输出、缓存和个人界面配置不提交
- 调试失败也可以记录，重点写清现象、原因和解决过程
- 大改动前创建新分支，验证完成后再合并到 `main`
